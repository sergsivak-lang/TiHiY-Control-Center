# Як імпортувати XML у Star Citizen

1. Скопіюй готовий XML у папку гри:

```text
Roberts Space Industries\StarCitizen\LIVE\USER\Client\0\Controls\Mappings\
```

Якщо у тебе PTU/EPTU, заміни `LIVE` на відповідну папку.

2. Запусти Star Citizen.
3. Відкрий:

```text
Options → Keybindings → Advanced Controls Customization
```

4. Унизу відкрий:

```text
Control Profiles → Import Control Settings
```

5. Вибери XML, який зберіг TiHiY Control Center.
6. Признач пристрої:

```text
Keyboard → Keyboard
Mouse → Mouse
Joystick → T.16000M
```

7. Натисни Apply.
8. Перевір у Arena Commander / Free Flight.
