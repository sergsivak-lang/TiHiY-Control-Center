# TiHiY System Optimizer v0.1

Перша робоча версія інтуїтивного майстра оптимізації Windows.

- збирає CPU, GPU, RAM, Windows, BIOS і план живлення;
- показує зрозумілі рекомендації з вибором так/ні;
- змінює тільки після підтвердження;
- створює резервні копії реєстру та журнал;
- підтримує Game Mode, Game DVR, HAGS, прискорення миші та план живлення;
- збирається GitHub Actions в один self-contained EXE для Windows x64.

Резервні копії: `%ProgramData%\TiHiY\SystemOptimizer\Backups`.
